# Excel

Last updated: 2026-11-05

## Current features

### Copilot skills for Excel
- **Status:** Preview
- **Last change:** 2026-08, custom skills built with Office.js in Beta and Current Channel (Preview)
- **More info:** [Create a Copilot skill for Excel that uses the Office JavaScript Library (preview)](https://learn.microsoft.com/office/dev/add-ins/excel/excel-copilot-skill)

Developers can package custom skills that Copilot in Excel invokes with @skill-name. A skill runs an Office.js script on the workbook, for example to add formulas, formatting or charts. It needs Excel version 2608 or later in the Beta or Current Channel (Preview) and is not meant for production use.

### Navigate to workbook changes from Copilot chat
- **Status:** Rolling out
- **Last change:** 2026-11-05, 2026-11-04, chat responses link to changed sheets, tables and ranges
- **More info:** [Microsoft 365 Copilot release notes](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)

Copilot chat responses in Excel now include clickable links that take you to the new or changed sheets, tables, ranges and objects in the workbook. It helps end users check what Copilot changed. Available on Windows, Web and Mac.
