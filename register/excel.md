# Excel

Last updated: 2026-11-26

## Current features

### Accounting skills in Copilot in Excel
- **Status:** Preview
- **Last change:** 2026-11-26, rolling out to the Frontier program in Excel and Cowork
- **More info:** [Use built-in skills and skills created by Microsoft with Copilot in Excel](https://support.microsoft.com/excel/copilot/copilot-in-excel-built-in-skills)

Microsoft-built skills help finance users with period-end close, account reconciliation, journal entries, financial statements, audit and compliance support, tax preparation and budget and variance analysis. Users find them in the Accounting folder of the Manage plugins dialog. Copilot does not give professional accounting advice, so output must be checked. Available through the Frontier program.

### Copilot in read-only workbooks
- **Status:** Rolling out
- **Last change:** 2026-11-26, rolling out to Excel for Windows, Mac and web
- **More info:** [What's New in Excel (November 2026)](https://techcommunity.microsoft.com/blog/excelblog/whats-new-in-excel-november-2026/4573867)

End users can open Copilot on a workbook that is read-only and ask questions about it in chat, such as what the data shows or which figures stand out. Copilot does not change the workbook. Available in Excel for Windows, Mac and web.

### Copilot skills for Excel
- **Status:** Preview
- **Last change:** 2026-08, custom skills built with Office.js in Beta and Current Channel (Preview)
- **More info:** [Create a Copilot skill for Excel that uses the Office JavaScript Library (preview)](https://learn.microsoft.com/office/dev/add-ins/excel/excel-copilot-skill)

Developers can package custom skills that Copilot in Excel invokes with @skill-name. A skill runs an Office.js script on the workbook, for example to add formulas, formatting or charts. It needs Excel version 2608 or later in the Beta or Current Channel (Preview) and is not meant for production use.

### Descriptive formula error cards
- **Status:** Rolling out
- **Last change:** 2026-11-26, rolling out in Excel for Windows version 2611 (build 16.0.20625.20000) or later
- **More info:** [What's New in Excel (November 2026)](https://techcommunity.microsoft.com/blog/excelblog/whats-new-in-excel-november-2026/4573867)

When a user hovers over a formula error indicator, a card explains what the error means, its possible causes and how to resolve it. For supported errors a "Fix this error" button asks Copilot to diagnose and repair the formula. Available in Excel for Windows.

### Edit with Copilot in Excel on iPhone
- **Status:** GA
- **Last change:** 2026-11-26, launched on Microsoft 365 Roadmap, background tasks available on iPhone
- **More info:** [Microsoft 365 Roadmap item 577177](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=577177)

End users can edit and transform workbooks on iPhone with natural-language requests. Copilot keeps working on a task in the cloud after the user leaves the app and sends a notification when it is done. Chat mode remains available for questions that do not change the workbook.

### Fabric IQ in Excel
- **Status:** Preview
- **Last change:** 2026-11-17, announced at Ignite 2026, preview
- **More info:** [Introducing the new Microsoft IQ: putting your organization's intelligence to work in every agent](https://azure.microsoft.com/en-us/blog/introducing-the-new-microsoft-iq-putting-your-organizations-intelligence-to-work-in-every-agent)

With Edit with Copilot in Excel, users can ask questions of governed Power BI semantic models through Fabric IQ. Copilot can create live PivotTables connected to Fabric, so the numbers come from the organization's shared model instead of copied data.

### Navigate to workbook changes from Copilot chat
- **Status:** Rolling out
- **Last change:** 2026-11-05, 2026-11-04, chat responses link to changed sheets, tables and ranges
- **More info:** [Microsoft 365 Copilot release notes](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)

Copilot chat responses in Excel now include clickable links that take you to the new or changed sheets, tables, ranges and objects in the workbook. It helps end users check what Copilot changed. Available on Windows, Web and Mac.
