# PowerPoint

Last updated: 2026-10-28

## Current features

### Attach a deck or image to a Copilot presentation
- **Status:** Rolling out
- **Last change:** 2026-10-27, Windows and web
- **More info:** [Release Notes for Microsoft 365 Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

When creating a presentation, users can attach an existing deck so Copilot applies its theme and styles, or attach an image that Copilot works into the slides. Used by end users with a Microsoft 365 Copilot license.

### Copilot web sources and enterprise assets in PowerPoint
- **Status:** Rolling out
- **Last change:** 2026-08, web source references on Mac, Adobe Experience Manager assets on the web
- **More info:** [Microsoft 365 Copilot release notes](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

When creating a presentation, Copilot in PowerPoint can reference online sources (Mac) and use images from an organization's Adobe Experience Manager library once an admin connects it to Microsoft 365 (web). End users can also start a Copilot presentation straight from PowerPoint on the web. A Microsoft 365 Copilot license is needed.

### Custom skills in Copilot in PowerPoint
- **Status:** Rolling out
- **Last change:** 2026-10-06, Create custom skill on Windows; web listed 2026-09-23
- **More info:** [Release Notes for Microsoft 365 Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

Users can define their own commands and workflows through Create custom skill in the Copilot pane, so Copilot repeats a personal way of working. It is aimed at end users with a Microsoft 365 Copilot license.

### Reference SharePoint and OneDrive files in Copilot prompts
- **Status:** Rolling out
- **Last change:** 2026-10-06, Mac (Roadmap ID 555897)
- **More info:** [Release Notes for Microsoft 365 Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

When creating a presentation, Copilot in PowerPoint recognizes files saved in SharePoint libraries and OneDrive folders that are named in the prompt. Users no longer attach them by hand. A Microsoft 365 Copilot license is needed.
