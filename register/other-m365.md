# Other Microsoft 365 apps

Last updated: 2026-11-27

## Current features

### Access form controls with rounded corners
- **Status:** Preview
- **Last change:** 2026-11-21, Corner Radius property available in Beta Channel 2612 and Current Channel (Preview) 2611
- **More info:** [Give your Access forms a fresh look with rounded corners](https://techcommunity.microsoft.com/blog/accessblog/give-your-access-forms-a-fresh-look-with-rounded-corners/4573058)

A new Corner Radius property in Access for Microsoft 365 rounds the corners of form controls. Developers set it in the property sheet or with VBA. It works on ten form controls, including text boxes, combo boxes, list boxes, labels, images, charts and subforms. Report controls, lines, check boxes and tab controls are not supported yet.

### Access management for Copilot Analytics
- **Status:** Roadmap
- **Last change:** 2026-11-26, added to the Microsoft 365 Roadmap, planned for January 2027
- **More info:** [Microsoft 365 Roadmap item 578862](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=578862)

Global, AI and Viva Insights admins will manage who can use Viva Insights Copilot Analytics, and what they can do, directly in the product. Access policies combine a permission set (what users can do) with a partition (whose data they can see). Replaces managing access through Viva Feature Access Management and in-product Manager settings.

### Agent insights in Viva Insights without an Agent 365 license
- **Status:** Roadmap
- **Last change:** 2026-11-17, announced at Ignite 2026, Agent 365 license no longer needed
- **More info:** [What's new in Microsoft Agent 365: Ignite 2026](https://techcommunity.microsoft.com/blog/agent-365-blog/whats-new-in-microsoft-agent-365-ignite-2026/4571753)

Eligible organizations can use agent insights in Viva Insights without an Agent 365 license. They still need at least 50 Microsoft 365 Copilot licenses. Analysts and leaders use it to see how agents are used.

### Communities in Teams
- **Status:** GA
- **Last change:** 2026-11-17, generally available, announced at Ignite 2026
- **More info:** [From conversations to intelligence: What's new for Viva Engage at Microsoft Ignite 2026](https://techcommunity.microsoft.com/blog/Viva_Engage_Blog/from-conversations-to-intelligence-whats-new-for-viva-engage-at-microsoft-ignite/4572999)

Employees can discover and take part in Viva Engage communities from inside Teams, without opening Viva Engage separately. Microsoft plans further work on navigation, mobile, notifications and discovery.

### Copilot Analytics: Cowork adoption and impact (Viva Insights)
- **Status:** GA
- **Last change:** 2026-10-06, released on web
- **More info:** [Release Notes for Microsoft 365 Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

Adds expanded Cowork adoption and impact metrics to the Copilot and Consumption dashboards in Viva Insights, with export and advanced-insights queries. Admins and analysts use it to see how Cowork is used.

### Microsoft Classroom
- **Status:** Roadmap
- **Last change:** 2026-11-25, added to the Microsoft 365 Roadmap: preview February 2027, general availability June 2027
- **More info:** [Microsoft 365 Roadmap item 580883](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=580883)

A standalone Microsoft 365 app for schools and universities that brings Assignments, Classwork, Grades, OneNote Class Notebook, Learning Accelerators and Insights together in one place. A personal Home shows educators and students what needs attention, and each class gets a shared Class Home set up by the educator. It is an alternative to Teams for Education and Microsoft 365 LTI.

### Microsoft To Do apps
- **Status:** Retiring
- **Last change:** 2026-11-18, To Do apps scheduled to retire on June 30, 2027
- **More info:** [Introducing unified tasks and plans for Copilot and Microsoft 365](https://techcommunity.microsoft.com/blog/plannerblog/introducing-unified-tasks-and-plans-for-copilot-and-microsoft-365/4573958)

The Microsoft To Do apps are scheduled to retire on June 30, 2027, as personal tasks move into Planner. New private tasks go to a private plan in Planner, and existing To Do tasks are visible in Planner but are not migrated. Users with a personal Microsoft account need to choose another app. Microsoft says a separate retirement notice will follow.

### Viva Engage plugin for Cowork
- **Status:** GA
- **Last change:** 2026-11-17, generally available
- **More info:** [What's new in Copilot Cowork at Ignite 2026](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/whats-new-in-copilot-cowork-at-ignite-2026/4572242)

A plugin that lets Copilot Cowork summarize Viva Engage community conversations and draft community announcements. Used by community managers and communicators with a Copilot license.

### Viva Glint bulk participant removal
- **Status:** Roadmap
- **Last change:** 2026-11-27, announced in the November 2026 Viva Glint News to Know, general availability planned for December 2026
- **More info:** [News to Know, Volume 3, Edition 12, November 2026](https://techcommunity.microsoft.com/blog/viva_glint_blog/news-to-know-%E2%80%93-volume-3-edition-12-november-2026/4576732)

Viva Glint admins can upload a file to remove any number of participants from a closed survey, instead of 25 at a time. Removal permanently deletes the participant's survey response, admins can review the outcome, and the action is recorded in the audit log.
