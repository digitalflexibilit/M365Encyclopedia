# Planner

Last updated: 2026-10-21

## Current features

### Planner Agent
- **Status:** Rolling out
- **Last change:** 2026-09, Planner Agent chat added; 2026-08, Planner Agent in group-based basic plans
- **More info:** [Turn off or restrict access to Planner Agent and Planner Agent chat in Planner](https://learn.microsoft.com/planner/turn-off-planner-agent)

Planner Agent automates plan creation, task execution and status reporting for teams, and is available in basic and premium group-based plans. Planner Agent chat in premium plans lets users ask questions and update tasks in natural language. Users need a Microsoft Copilot license, and admins control access with Set-PlannerConfiguration -AllowPlannerCopilot. Replaces Copilot in Planner.
