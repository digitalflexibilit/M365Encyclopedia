# Outlook

Last updated: 2026-10-28

## Current features

### Copilot email triage actions
- **Status:** Rolling out
- **Last change:** 2026-09-23, delete, move, copy, categorize and folder and rule management added
- **More info:** [Triage email with Microsoft Copilot in Outlook](https://support.microsoft.com/en-us/outlook/triage-email-with-microsoft-365-copilot-in-outlook)

Users ask Copilot in plain language to archive, delete, move, copy, flag or categorize messages, create folders and help create inbox rules. It works in Copilot Chat and in Outlook on Windows, web, Mac and mobile. Actions on more than five emails need confirmation. English only.

### Copilot settings in classic Outlook
- **Status:** Rolling out
- **Last change:** 2026-10-27, Windows
- **More info:** [Release Notes for Microsoft 365 Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

Copilot settings are available directly in classic Outlook for Windows under File, Copilot settings. The settings respect existing Outlook client security policies. Used by end users with Copilot.

### Schedule with Copilot in classic Outlook
- **Status:** Rolling out
- **Last change:** 2026-08-25, feature listed
- **More info:** [Release Notes for Microsoft 365 Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

In classic Outlook for Windows, users can ask Copilot in chat, or use the Schedule with Copilot button, to find times, book rooms, draft an agenda and send the invite. Needs a Microsoft 365 Copilot license and is rolling out in phases.
