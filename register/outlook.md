# Outlook

Last updated: 2026-11-26

## Current features

### Account selector in the Copilot side pane
- **Status:** Rolling out
- **Last change:** 2026-11-05, 2026-11-04, account dropdown in the Calendar Copilot side pane of new Outlook
- **More info:** [Microsoft 365 Copilot release notes](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)

When several Copilot-enabled accounts are added to new Outlook, the Calendar Copilot side pane shows an account dropdown. End users use it to see and switch the active account.

### Copilot Chat in shared and delegate mailboxes
- **Status:** Rolling out
- **Last change:** 2026-11-26, rolling out in classic Outlook for Windows
- **More info:** [Microsoft 365 Roadmap item 573698](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=573698)

Users who have full access or folder-level permission on a shared or delegate mailbox can open Copilot Chat directly from that mailbox in classic Outlook, when the mailbox is added as a resource. It lets assistants and team members use Copilot on mail they manage for others without switching to their own mailbox.

### Copilot email triage actions
- **Status:** Rolling out
- **Last change:** 2026-09-23, delete, move, copy, categorize and folder and rule management added
- **More info:** [Triage email with Microsoft Copilot in Outlook](https://support.microsoft.com/en-us/outlook/triage-email-with-microsoft-365-copilot-in-outlook)

Users ask Copilot in plain language to archive, delete, move, copy, flag or categorize messages, create folders and help create inbox rules. It works in Copilot Chat and in Outlook on Windows, web, Mac and mobile. Actions on more than five emails need confirmation. English only.

### Copilot settings in classic Outlook
- **Status:** Rolling out
- **Last change:** 2026-10-27, Windows
- **More info:** [Release Notes for Microsoft 365 Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

Copilot settings are available directly in classic Outlook for Windows under File, Copilot settings. The settings respect existing Outlook client security policies. Used by end users with Copilot.

### Custom engine agents in Outlook
- **Status:** Rolling out
- **Last change:** 2026-11-19, listed in the November 17, 2026 release notes
- **More info:** [Microsoft 365 Copilot release notes](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)

Users can run custom engine agents from the agent pane in Outlook on the web to automate email tasks such as sorting or summarizing messages. Developers build the agents and admins make them available.

### Custom flag descriptions
- **Status:** Roadmap
- **Last change:** 2026-11-25, added to the Microsoft 365 Roadmap, planned for February 2027
- **More info:** [Microsoft 365 Roadmap item 580885](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=580885)

In new Outlook for Windows, users can add their own text to an email's follow-up flag to note the next step. This reminds them why they flagged the message.

### Folder pane remembers expanded folders
- **Status:** Roadmap
- **Last change:** 2026-11-11, added to roadmap, planned for February 2027
- **More info:** [Microsoft 365 Roadmap item 579187](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579187)

New Outlook for Windows and Outlook on the web remember which folders, shared mailboxes and online archives are expanded or collapsed, also after a restart. A related change lets users expand or collapse all accounts in the folder pane at once.

### Folder sharing follows organization policy
- **Status:** Roadmap
- **Last change:** 2026-11-14, added to the Microsoft 365 Roadmap, planned for January 2027
- **More info:** [Microsoft 365 Roadmap item 579185](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579185)

In new Outlook for Windows, folder sharing will respect the organization's restrictions on Default and Anonymous permissions. When the restrictions are on, users cannot change those two settings. Permissions given directly to individual users are not affected.

### Manage multiple inbox rules at once
- **Status:** Rolling out
- **Last change:** 2026-11-26, rolling out in new Outlook for Windows and Outlook on the web
- **More info:** [Microsoft 365 Roadmap item 569430](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=569430)

End users can select several or all of their inbox rules and delete, enable or disable them in one action. It makes it faster to clean up and organize rules in new Outlook for Windows and Outlook on the web.

### Message list sort improvements
- **Status:** Rolling out
- **Last change:** 2026-11-19, listed in the November 17, 2026 release notes (roadmap item 564803)
- **More info:** [Microsoft 365 Copilot release notes](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)

When users sort the message list by a field other than From, Subject or Date Received, Outlook on Windows shows a column with the sort value. Sorting by Flag Due Date is also supported.

### Recoverable items storage usage
- **Status:** Roadmap
- **Last change:** 2026-11-11, added to roadmap, planned for February 2027
- **More info:** [Microsoft 365 Roadmap item 579190](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579190)

New Outlook for Windows and Outlook on the web show how much mailbox storage recoverable items use. Users can see this before they reach a limit and decide how to manage their mailbox.

### Schedule with Copilot in classic Outlook
- **Status:** Rolling out
- **Last change:** 2026-08-25, feature listed
- **More info:** [Release Notes for Microsoft 365 Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

In classic Outlook for Windows, users can ask Copilot in chat, or use the Schedule with Copilot button, to find times, book rooms, draft an agenda and send the invite. Needs a Microsoft 365 Copilot license and is rolling out in phases.

### Share availability
- **Status:** Roadmap
- **Last change:** 2026-11-25, added to the Microsoft 365 Roadmap, planned for January 2027
- **More info:** [Microsoft 365 Roadmap item 580444](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=580444)

In new Outlook, users pick free time slots from their calendar, or while writing an email, and insert them into the message without typing dates and times. For one-on-one meetings, the recipient can book one of the proposed times with one click.

### Sort subfolders from A to Z
- **Status:** Roadmap
- **Last change:** 2026-11-11, added to roadmap, planned for February 2027
- **More info:** [Microsoft 365 Roadmap item 579186](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579186)

Users sort all subfolders of a folder alphabetically from the parent folder in new Outlook for Windows and Outlook on the web, instead of moving them one by one.

### Updated Copilot Chat sheet in Outlook mobile
- **Status:** Roadmap
- **Last change:** 2026-11-12, added to roadmap, planned for December 2026
- **More info:** [Microsoft 365 Roadmap item 579897](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579897)

Copilot Chat in Outlook for iOS and Android gets smoother animations, clearer text and a simpler header. The new chat and temporary chat button moves behind the "..." menu.
