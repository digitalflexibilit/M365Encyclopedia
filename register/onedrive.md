# OneDrive

Last updated: 2026-10-25

## Current features

### Copilot in OneDrive
- **Status:** GA
- **Last change:** 2026-10-20, generally available, rebuilt on the same foundation as Copilot in SharePoint
- **More info:** [OneDrive Just Got a Major Upgrade](https://techcommunity.microsoft.com/blog/onedriveblog/onedrive-just-got-a-major-upgrade-new-copilot-capabilities-simpler-sharing-and-s/4565995)

Copilot in OneDrive helps end users work across files: analyze several files together, organize a folder or project, and create content such as HTML reports from existing files. Users can save repeated processes as custom skills in Markdown, and edit and comment on HTML and Markdown files. A Prompt Gallery and photo features (find photos by description, slideshows) are included.

### Hero Links
- **Status:** Rolling out
- **Last change:** 2026-10-20, rolling out
- **More info:** [OneDrive Just Got a Major Upgrade](https://techcommunity.microsoft.com/blog/onedriveblog/onedrive-just-got-a-major-upgrade-new-copilot-capabilities-simpler-sharing-and-s/4565995)

Each file or folder gets one default link. Changing permissions updates the same URL instead of creating a new link. Expiring access for Hero Links is announced as coming soon.
