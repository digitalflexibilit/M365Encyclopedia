# OneDrive

Last updated: 2026-11-22

## Current features

### Archiving and sync controls
- **Status:** Roadmap
- **Last change:** 2026-11-22, file archive policies for OneDrive accounts in public preview through PowerShell, see File archive policies in the SharePoint register
- **More info:** [SharePoint and OneDrive at Microsoft Ignite 2026](https://techcommunity.microsoft.com/blog/spblog/sharepoint-and-onedrive-at-microsoft-ignite-2026-putting-ai-powered-content-to-w/4535416)

New lifecycle and sync controls for admins: policy-based archiving of inactive files with a what-if analysis, folder-level sync exclusions and a OneDrive Sync command-line tool. OneDrive sync also supports up to one million items on Windows and macOS.

### Copilot in OneDrive
- **Status:** GA
- **Last change:** 2026-10-20, generally available, rebuilt on the same foundation as Copilot in SharePoint
- **More info:** [OneDrive Just Got a Major Upgrade](https://techcommunity.microsoft.com/blog/onedriveblog/onedrive-just-got-a-major-upgrade-new-copilot-capabilities-simpler-sharing-and-s/4565995)

Copilot in OneDrive helps end users work across files: analyze several files together, organize a folder or project, and create content such as HTML reports from existing files. Users can save repeated processes as custom skills in Markdown, and edit and comment on HTML and Markdown files. A Prompt Gallery and photo features (find photos by description, slideshows) are included.

### Hero Links
- **Status:** Rolling out
- **Last change:** 2026-10-20, rolling out
- **More info:** [OneDrive Just Got a Major Upgrade](https://techcommunity.microsoft.com/blog/onedriveblog/onedrive-just-got-a-major-upgrade-new-copilot-capabilities-simpler-sharing-and-s/4565995)

Each file or folder gets one default link. Changing permissions updates the same URL instead of creating a new link. Expiring access for Hero Links is announced as coming soon.

### Libraries view
- **Status:** GA
- **Last change:** 2026-11-21, roadmap status Launched, highlighted at Ignite 2026
- **More info:** [Microsoft 365 Roadmap item 566315](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=566315)

Replaces the More places page in OneDrive on the web with a Libraries view that lists recently used SharePoint libraries, Teams libraries and favorite sites. End users can filter by keyword, sort by recent activity or name, and switch between list and tile views. Replaces More places.
