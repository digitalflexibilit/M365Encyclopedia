# Power BI

Last updated: 2026-11-08

## Current features

### Artifact info header for Power BI tabs in Teams
- **Status:** GA
- **Last change:** 2026-11-06, included in the October 2026 Power BI update
- **More info:** [Embed Power BI content in Microsoft Teams](https://learn.microsoft.com/en-us/power-bi/collaborate-share/office-integration/service-embed-report-microsoft-teams)

Power BI tabs in Teams show a header with the content name, most recent data refresh time and sensitivity label. It covers reports, dashboards, scorecards, apps and org apps, and helps viewers judge how current the data is.

### Auto-expand hierarchy axis with field parameters
- **Status:** GA
- **Last change:** 2026-11-08, included in the October 2026 Power BI update
- **More info:** [Customize x-axis and y-axis properties](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-customize-x-axis-and-y-axis)

Bar, column and line charts expand hierarchy axes automatically when several columns are selected, including columns supplied by field parameters. Report viewers can switch axis fields through a slicer or Personalize this visual.

### Chart plot area background color
- **Status:** GA
- **Last change:** 2026-11-08, included in the October 2026 Power BI update
- **More info:** [Format report visualizations](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualizations-format-visual)

Report creators can set a solid fill for the plot area of bar, column, line, area, combo, ribbon, waterfall and scatter charts. The fill can also follow conditional formatting based on a measure or field value.

### Continuous capacity usage reporting for surge protection
- **Status:** GA
- **Last change:** 2026-11-08, included in the October 2026 Power BI update
- **More info:** [Surge protection](https://learn.microsoft.com/en-us/fabric/enterprise/surge-protection)

Semantic models now report capacity unit usage continuously during long-running background operations instead of mostly at completion. Surge protection can then reject or delay work earlier. No settings change is needed. Used by capacity admins.

### Gantt chart visual
- **Status:** Preview
- **Last change:** 2026-11-04, a new core visual for task durations, progress and milestones (October 2026 update)
- **More info:** [Gantt visual in Power BI](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-gantt)

The Gantt chart shows task durations, progress and milestones on a time axis. Report creators can set axis ranges, category colors, extra task columns and a zoom axis. Enable it under Preview features in Power BI Desktop and restart Desktop.

### List slicer dropdown mode
- **Status:** Preview
- **Last change:** 2026-11-04, dropdown mode and Show selected first (October 2026 update)
- **More info:** [Create and use a list slicer](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-list-slicer)

List slicers can show as a dropdown with dismissible selection pills, configurable drawer size and search formatting. Show selected first pins active selections to the top of list and button slicers. Report creators use it to save space on a page.

### Mobile page indicator
- **Status:** GA
- **Last change:** 2026-11-08, included in the October 2026 Power BI update
- **More info:** [Identify report pages that have a mobile layout](https://learn.microsoft.com/en-us/power-bi/explore-reports/mobile/mobile-whats-new-in-the-mobile-apps)

Report page tabs in the report footer show an icon when a page has a mobile layout. Report creators can see which pages are mobile-ready and which still need a layout.

### Personal bookmarks preserve column widths
- **Status:** GA
- **Last change:** 2026-11-08, included in the October 2026 Power BI update
- **More info:** [Personal bookmarks in Power BI](https://learn.microsoft.com/en-us/power-bi/explore-reports/end-user-bookmarks)

Personal bookmarks keep resized and reordered columns in tables and matrices, so applying a bookmark restores the saved layout. Used by report viewers.

### Power BI Q&A
- **Status:** Retiring
- **Last change:** 2026-11-01, retirement now stated as February 2027 (earlier documentation said December 2026)
- **More info:** [Introduction: Use natural language to explore data with Power BI Q&A](https://learn.microsoft.com/en-us/power-bi/natural-language/q-and-a-intro)

Q&A is the legacy natural language tool that answers questions about a semantic model as charts, on dashboards and in Q&A visuals. It is used by business users and report designers. Microsoft recommends Copilot for Power BI instead.

### Power BI Report skill: custom visuals
- **Status:** GA
- **Last change:** 2026-11-04, can add and format custom visuals (October 2026 update)
- **More info:** [Power BI Report skill](https://learn.microsoft.com/en-us/power-bi/developer/agentic/power-bi-report-skill-overview)

The Power BI Report skill in Skills for Fabric can add supported custom visuals to a report, bind them to report data, apply formatting and validate the result. It can use visuals already imported or help find an AppSource visual. Report creators use it through an AI agent.

### Power BI semantic models in Copilot via Fabric IQ
- **Status:** GA
- **Last change:** 2026-09-25, feature listed
- **More info:** [Introducing the new Copilot with Home, Code and Autopilot](https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/)

Fabric IQ brings governed Power BI semantic models into Copilot Chat and Cowork, so users get answers grounded in existing reports and models.
