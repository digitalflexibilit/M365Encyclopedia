# Power BI

Last updated: 2026-11-01

## Current features

### Power BI Q&A
- **Status:** Retiring
- **Last change:** 2026-11-01, retirement now stated as February 2027 (earlier documentation said December 2026)
- **More info:** [Introduction: Use natural language to explore data with Power BI Q&A](https://learn.microsoft.com/en-us/power-bi/natural-language/q-and-a-intro)

Q&A is the legacy natural language tool that answers questions about a semantic model as charts, on dashboards and in Q&A visuals. It is used by business users and report designers. Microsoft recommends Copilot for Power BI instead.

### Power BI semantic models in Copilot via Fabric IQ
- **Status:** GA
- **Last change:** 2026-09-25, feature listed
- **More info:** [Introducing the new Copilot with Home, Code and Autopilot](https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/)

Fabric IQ brings governed Power BI semantic models into Copilot Chat and Cowork, so users get answers grounded in existing reports and models.
