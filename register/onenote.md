# OneNote

Last updated: 2026-11-07

## Current features

### Copilot Notebooks in OneNote
- **Status:** GA
- **Last change:** 2026-10-27, multimodal capture added on Android; 2026-07, available in OneNote on the web, iPhone and iPad
- **More info:** [Microsoft 365 Copilot release notes](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

Copilot Notebooks bring notes, Office files and Copilot chats into one workspace that Copilot uses as context. End users can create them in OneNote on Windows, the web, iPhone and iPad, and OneNote on iPhone, iPad and Android can capture audio, images and typed notes in one session. A Microsoft 365 Copilot license is needed. The lighter Notebooks design in the Microsoft 365 Copilot app (September 2026) sits next to the fuller OneNote experience.

### OneNote support in Copilot Cowork
- **Status:** Rolling out
- **Last change:** 2026-11-07, listed in the November 2026 Cowork release notes
- **More info:** [Work with OneNote notebooks in Cowork](https://learn.microsoft.com/en-us/copilot/cowork/use-cowork#work-with-onenote-notebooks)

Lets Copilot Cowork find and read OneNote notebooks the user can access, summarize pages and use the notes for related tasks. Where editing is available, Cowork can add, replace or delete paragraphs, add a table, rename a page or add a page to an existing section, after the user approves the edit. It cannot create notebooks or sections, and reading and editing availability can differ by session. A Microsoft 365 Copilot license and Cowork access are needed.
