# Digest 2026-11-07

## Copilot
- **OneNote support in Cowork** (OneNote, Rolling out): Cowork can find and read OneNote notebooks the user can access, summarize pages and use notes for related work. Where editing is available, it can update page content or add pages to existing sections after the user approves the change. It cannot create notebooks or sections, and availability can differ by session. [More info](https://learn.microsoft.com/en-us/copilot/cowork/use-cowork#work-with-onenote-notebooks)
