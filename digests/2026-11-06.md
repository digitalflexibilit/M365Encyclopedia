# Digest 2026-11-06

## Copilot
- **Cowork local Microsoft Edge browser use** (Microsoft 365 Copilot, Rolling out): Cowork can use the local Edge browser to complete web steps, including on sites the user is signed in to, in a separate Edge tab. Credentials, cookies and session tokens stay on the device. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)

## Power BI
- **Artifact info header for Power BI tabs in Teams** (Power BI, GA): Power BI tabs in Teams show the content name, last data refresh time and sensitivity label for reports, dashboards, scorecards, apps and org apps. [More info](https://learn.microsoft.com/en-us/power-bi/collaborate-share/office-integration/service-embed-report-microsoft-teams)
