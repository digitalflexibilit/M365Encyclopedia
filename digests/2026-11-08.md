# Digest 2026-11-08

## Power BI
- **Auto-expand hierarchy axis with field parameters** (Power BI, GA): Bar, column and line charts expand hierarchy axes automatically when several columns are selected, including columns supplied by field parameters. [More info](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-customize-x-axis-and-y-axis)
- **Chart plot area background color** (Power BI, GA): Report creators can set a solid fill for the plot area of bar, column, line, area, combo, ribbon, waterfall and scatter charts. [More info](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualizations-format-visual)
- **Continuous capacity usage reporting for surge protection** (Power BI, GA): Semantic models now report capacity unit usage continuously during long-running background operations instead of mostly at completion. [More info](https://learn.microsoft.com/en-us/fabric/enterprise/surge-protection)
- **Mobile page indicator** (Power BI, GA): Report page tabs in the report footer show an icon when a page has a mobile layout. [More info](https://learn.microsoft.com/en-us/power-bi/explore-reports/mobile/mobile-whats-new-in-the-mobile-apps)
- **Personal bookmarks preserve column widths** (Power BI, GA): Personal bookmarks keep resized and reordered columns in tables and matrices, so applying a bookmark restores the saved layout. [More info](https://learn.microsoft.com/en-us/power-bi/explore-reports/end-user-bookmarks)
