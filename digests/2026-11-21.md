# Digest 2026-11-21

## Copilot
- **GPT-6.2 Sol and GPT-6.2 Astra models** (Microsoft 365 Copilot, Rolling out): GPT-6.2 Sol is rolling out worldwide to eligible users in Copilot Chat, Cowork, Copilot Studio and Copilot in Word, Excel and PowerPoint. GPT-6.2 Astra is rolling out in Cowork and Copilot Studio, and for Frontier users also in Copilot Chat and the Office apps. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/available-today-openais-gpt-6-2-sol-and-gpt-6-2-astra-in-microsoft-copilot/4574229)
- **Copilot memory across Microsoft 365 apps** (Microsoft 365 Copilot, Rolling out): Memory is rolling out to general availability in Word, Excel, PowerPoint, Workspaces, Pages, Outlook and Teams, where it learns formatting, tone and work structure, and Copilot learns each user's email writing style for drafts. Authorized agents can read the memory profile through a Work IQ MCP tool. Admins can turn it off with the Enhanced personalization control. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/the-end-of-starting-over-how-work-iq-helps-copilot-understand-you-and-your-work/4571169)
- **Memory citations** (Microsoft 365 Copilot, GA): Responses shaped by memory list the instructions, memories and past chats that were used, and users can open a cited chat or delete a memory from there. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/the-end-of-starting-over-how-work-iq-helps-copilot-understand-you-and-your-work/4571169)
- **People and organizational context in Work IQ** (Microsoft 365 Copilot, Rolling out): Copilot answers questions about people and org structure from authoritative HR attributes, can calculate counts, ratios and rankings, and shows skills insights across teams, rolling out to GA through December. Organizational context, where admins add company terminology and definitions in the Workforce Insights Agent, is in Frontier. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/copilot-that-understands-your-organization-introducing-people-and-org-context-in/4573356)
- **Work IQ context enhancements** (Microsoft 365 Copilot, Preview): Custom agents on Work IQ get Copilot's document understanding for SharePoint and OneDrive content, including Markdown, images, summaries and in-file lookup. Rolling out to public preview from November. [More info](https://techcommunity.microsoft.com/blog/spblog/sharepoint-and-onedrive-at-microsoft-ignite-2026-putting-ai-powered-content-to-w/4535416)
- **Update: Learning agent** (Microsoft 365 Copilot, Rolling out): New AI upskilling tab, AI Skills Navigator playlists, starter prompts and prompt coaching, personalized with Work IQ memory. Admins can assign training, and in Frontier add their AI usage policy. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/learning-agent-build-ai-and-copilot-skills-through-everyday-work/4573000)
- **Update: Agent accounts** (Copilot Studio, Preview): Agent accounts, earlier a Frontier preview, move to public preview in December 2026. [More info](https://www.microsoft.com/en-us/copilot/blog/copilot-studio/build-and-manage-business-processes-with-microsoft-copilot-studio/)

## Teams
- **New meeting controls** (Teams, Rolling out): The redesigned meeting toolbar, with Leave separated from other controls and the option to pin, unpin and rearrange controls, is becoming broadly available. [More info](https://adoption.microsoft.com/en-us/microsoft-teams/new-meeting-controls-experience/)

## SharePoint
- **Content Governance Hub** (SharePoint, Roadmap): A new admin page, powered by the SharePoint Admin Agent, combines assessments, findings, recommendations and tasks. Announced at Ignite without a date. [More info](https://learn.microsoft.com/en-us/sharepoint/content-governance-agent)

## OneDrive
- **Archiving and sync controls** (OneDrive, Roadmap): Announced at Ignite: policy-based archiving of inactive files with what-if analysis, folder-level sync exclusions, a OneDrive Sync command-line tool and sync of up to one million items on Windows and macOS. No dates given. [More info](https://techcommunity.microsoft.com/blog/spblog/sharepoint-and-onedrive-at-microsoft-ignite-2026-putting-ai-powered-content-to-w/4535416)

## Power Apps
- **Microsoft Copilot in canvas apps** (Power Apps, Rolling out): Microsoft announced general availability this November for Copilot in canvas apps, which answers app users' questions about the app's Dataverse or SharePoint list data. It needs a Microsoft 365 Copilot license and replaces the Copilot control. [More info](https://www.microsoft.com/en-us/power-platform/blog/2026/11/18/turn-ai-ambition-into-real-business-value-with-power-platform/)
