# Digest 2026-11-24

## Teams
- **Report suspicious guest invitations** (Teams, Rolling out): When users decline an unexpected invitation to join another organization as a guest, they can report it to their IT admin and to Microsoft. It works on Windows, Mac and the web, is controlled by the existing Report a security concern messaging policy setting, and reports show in the Teams admin center (MC1530615). [More info](https://techcommunity.microsoft.com/blog/microsoftmissioncriticalblog/coffee-corner-november-2026-%E2%80%93-ews-countdown-teams-versions-and-guest-invitation-/4574377)

## Power BI
- **Filter action button for tables and matrices** (Power BI, Preview): Report creators can add a Filter button to table and matrix visuals so readers change that visual's filters in an overlay, even when the Filters pane is hidden. [More info](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualizations-action-buttons)

## Power Pages
- **Power Pages sites in Power Platform inventory** (Power Pages, Preview): Power Pages sites now appear in the tenant-wide inventory in the Power Platform admin center, so admins can find sites, owners, sites with anonymous access and public developer sites. Data can also be queried through Azure Resource Graph or the Power Platform API, and the rollout across regions is gradual. [More info](https://learn.microsoft.com/en-us/power-pages/admin/power-pages-inventory)

## Admin & governance
- **Local agents in the Microsoft 365 admin center** (Agent 365, Preview): Admins can see developer AI tools such as Claude Code, GitHub Copilot CLI and VS Code agent extensions on managed Windows devices and block some of them through Intune. Supported local agents can also get their own Entra Agent ID, and Intune can mark devices with unapproved agents as noncompliant. Requires the Frontier program and Intune enrollment. [More info](https://learn.microsoft.com/en-us/microsoft-agent-365/admin/agent-local)
