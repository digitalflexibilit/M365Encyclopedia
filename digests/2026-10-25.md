# Digest 2026-10-25

## Copilot
- **Update: Notebooks** (Microsoft 365 Copilot, Rolling out): Besides the new file types reported on 2026-10-23, Notebooks now has Frontier features: editing Word, Excel and PowerPoint files on the canvas, interactive reports, PDF creation, delegating simple work and model choice. Scheduled automations and new audio overview formats are announced for the next few weeks. Suggested artifacts are GA. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/whats-new-in-notebooks--october-2026/4559105)
- **Copilot in OneDrive** (OneDrive, GA): Copilot in OneDrive is generally available, rebuilt on the same foundation as Copilot in SharePoint. It can analyze several files, organize folders and projects, create HTML reports and save custom skills as Markdown. [More info](https://techcommunity.microsoft.com/blog/onedriveblog/onedrive-just-got-a-major-upgrade-new-copilot-capabilities-simpler-sharing-and-s/4565995)
- **Copilot Analytics: Cowork adoption and impact** (Viva Insights, GA): Expanded Cowork adoption and impact metrics in the Copilot and Consumption dashboards, with export and advanced-insights queries. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

## Microsoft 365 apps and admin
- **Hero Links** (OneDrive, Rolling out): One default link per file or folder, where changing permissions updates the same URL. Expiring access is coming soon. [More info](https://techcommunity.microsoft.com/blog/onedriveblog/onedrive-just-got-a-major-upgrade-new-copilot-capabilities-simpler-sharing-and-s/4565995)
- **Everyone except external users permissions report** (SharePoint, GA): Item-level report for SharePoint Advanced Management admins on content shared with the Everyone groups. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
