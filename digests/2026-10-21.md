# Digest 2026-10-21

## Copilot
- **Usage-based billing default for Copilot Business** (Microsoft 365 Copilot, Roadmap): Usage-based billing will be on by default for new Copilot Business licenses bought through CSP from 1 December 2026, moved from 2 November. The default limit is 4,000 Copilot Credits per user per month. [More info](https://learn.microsoft.com/en-us/partner-center/announcements/2026-october)
- **Copilot add-on SKU rename** (Microsoft 365 Copilot, Rolling out): From 16 October the Copilot offers that need a base subscription carry "(add-on)" in the name. From 1 December new Copilot offers can be bought without a base subscription at the same price. [More info](https://learn.microsoft.com/en-us/partner-center/announcements/2026-october)
- **Office in Copilot** (Microsoft 365 Copilot, Rolling out): Word, Excel and PowerPoint are built into the Copilot app for Frontier customers in Chat and Cowork. Documents stay editable and in sync with the Office apps. [More info](https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/)
- **Autopilot, Code and Home** (Microsoft 365 Copilot, Preview): Home and Code roll out in the Frontier program, and Autopilot expands to private preview at the end of the month. [More info](https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/)
- **Copilot Cost Management API and cost dashboard** (Microsoft 365 Copilot, GA): Admins can manage spending policies and read Copilot Credit consumption through Microsoft Graph and the admin center. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/usage-based-billing-overview-copilot-credits)
- **Copilot for legal** (Word, GA): More than 20 legal skills for contract drafting, redlining and review, on by default in Word desktop for commercial Copilot subscribers. [More info](https://learn.microsoft.com/en-us/microsoft-365/admin/manage/manage-copilot-for-legal?view=o365-worldwide)
- **Copilot Studio build 2026.6.3** (Copilot Studio, GA): New agent management API endpoints, per-agent analytics and a default GPT-5 Mini fine-tuned model. Skill agents now block unsupported reference file types. [More info](https://learn.microsoft.com/en-us/power-platform/released-versions/copilotstudio/2026.6.3)

## Microsoft 365 apps and admin
- **Schedule with Copilot** (Outlook, Rolling out): Copilot can schedule meetings from chat in classic Outlook for Windows. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
- **Pause all notifications and VDI town halls** (Teams, Rolling out): Users can pause notifications temporarily, and town hall attendees on virtual desktops can offload audio and video. [More info](https://learn.microsoft.com/en-us/officeupdates/teams-admin)
- **Office LTSC 2021 end of support** (Admin, Retiring): Support for Office, Project and Visio LTSC 2021 ended on 13 October. Copilot is not supported on these versions. [More info](https://learn.microsoft.com/en-us/partner-center/announcements/2026-october)

## Power Platform
- **End of AI Builder credits** (AI Builder, Retiring): On 1 November 2026 AI Builder capacity add-ons reach end of life and new premium licenses carry no seeded credits. Features continue using Copilot Credits. [More info](https://learn.microsoft.com/en-us/ai-builder/endofaibcredits)
- **MCP server for Power Pages** (Power Pages, Preview): AI agents can work with Dataverse data through a site while respecting web roles. GA is planned for December 2026. [More info](https://learn.microsoft.com/en-us/power-pages/configure/mcp-overview)
- **Compare desktop flow versions** (Power Automate, GA): Side-by-side comparison of desktop flow versions stored in Dataverse. [More info](https://learn.microsoft.com/en-us/power-platform/release-plan/2026wave1/power-automate/compare-versions)
