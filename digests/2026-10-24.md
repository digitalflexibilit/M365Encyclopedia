# Digest 2026-10-24

## Copilot
- **Apps in Copilot Studio** (Copilot Studio, Preview): Makers describe an app in natural language, refine the generated draft in conversation, and combine it with workflows and agents in one solution. Apps run on Copilot Managed Runtime. [More info](https://www.microsoft.com/en-us/copilot/blog/copilot-studio/new-and-improved-build-apps-extend-agents-and-transform-business-processes-in-microsoft-copilot-studio/)
- **Hooks for agents** (Copilot Studio, Preview): For agents built with the GitHub Copilot harness, hooks run a workflow every time an event fires, such as session start, before or after a tool call, or an error. A pre tool use hook can block a call. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/hooks-overview)
- **Foundry IQ knowledge for agents** (Copilot Studio, GA): Agents can use a reusable Foundry IQ knowledge base as a tool, with citations and private networking. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/foundry-iq-connect)
- **Review panel** (Copilot Studio, GA): Shows blocking issues and warnings while building an agent, including data policy restrictions, before publishing. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/authoring-agent-status)
