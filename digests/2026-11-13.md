# Digest 2026-11-13

## Copilot
- **Power Platform Admin in Cowork** (Copilot Cowork / Power Platform admin, Preview): A Cowork plugin lets Power Platform, Dynamics 365 and Global admins ask plain-language questions about environments, inventory, usage, ownership, capacity and licensing, then turn answers into reports, owner emails or scheduled briefings. It is read-only and consumes Copilot Credits. [More info](https://learn.microsoft.com/en-us/power-platform/admin/power-platform-admin-cowork)

## Power Apps
- **Authoring agent in canvas studio** (Power Apps, Preview): An agent pane in Power Apps Studio plans and then builds or edits a canvas app from a plain-language description. Makers sign in with GitHub, which bills the usage, and a tenant admin must enable the setting. United States and English only. [More info](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/canvas-authoring-agent)
- **AI row summaries in the modern Data Grid** (Power Apps, Preview): Canvas app Data Grids bound to a Dataverse table can show the table's AI row summary per record. Makers set ShowAIRowSummary and an admin must allow "Summary in canvas data grid". [More info](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/controls/modern-controls/modern-control-data-grid#ai-row-summaries)
- **Data Grid pagination** (Power Apps, Rolling out): The modern Data Grid can load records on scroll or show numbered pages with an adjustable page size. Off by default, so existing apps do not change. [More info](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/controls/modern-controls/modern-control-data-grid#pagination)
- **Dataverse.Unmask function** (Power Apps, Preview): A Power Fx function that requests the unmasked value of one masked Dataverse column for a single record, with Dataverse permissions still applied. [More info](https://learn.microsoft.com/en-us/power-platform/power-fx/reference/function-dataverse-unmask)
- **Generative pages: custom APIs and telemetry** (Power Apps, Preview): Generative pages in model-driven apps can call Dataverse custom APIs for server-side logic as the signed-in user, and can export telemetry to Application Insights once an admin sets up the export. [More info](https://learn.microsoft.com/en-us/power-apps/maker/model-driven-apps/generative-pages)

## Power Automate
- **Scheduled triggers for desktop flows** (Power Automate, Preview): Desktop flows can run on a recurring schedule from the Automation center without a separate cloud flow. Rolling out gradually by region. [More info](https://learn.microsoft.com/en-us/power-automate/schedule-desktop-flows)
- **Flowchart mode for desktop flows** (Power Automate, Preview): A visual node-and-connection canvas for building and debugging desktop flows, with step highlighting and error navigation. [More info](https://learn.microsoft.com/en-us/power-automate/desktop-flows/flowchart-flow-designer)
- **Desktop flow templates** (Power Automate, GA): Makers save, publish and share desktop flow templates. New flows created from a template are independent copies. Needs Power Automate for desktop 2.72 or later. [More info](https://learn.microsoft.com/en-us/power-automate/desktop-flows/create-desktop-flow-templates)

## Power Pages
- **Authentication governance controls** (Power Pages, Preview): Admins can allow or block sign-in protocols, the Google, Microsoft and Facebook providers, and local authentication for all or selected sites in the Power Platform admin center. Blocked options are greyed out for makers. [More info](https://learn.microsoft.com/en-us/power-pages/security/external-auth-control)
- **Non-SPA sites with agentic coding tools** (Power Pages, Preview): The Power Pages plugin 3.0.0 for GitHub Copilot CLI and Claude Code can now create and edit traditional sites built with web templates and Liquid. Requires the enhanced data model. [More info](https://www.microsoft.com/en-us/power-platform/blog/power-pages/create-and-edit-non-spa-power-pages-sites-with-agentic-coding-tools/)

## Admin and governance
- **Monitor alert routing** (Power Platform admin center, Preview): A "When an alert fires" trigger in the Power Platform for Admins V2 connector routes Monitor alerts through Power Automate to any connector-backed destination, such as Teams or a ticketing system. [More info](https://learn.microsoft.com/en-us/power-platform/admin/monitoring/alerts)
