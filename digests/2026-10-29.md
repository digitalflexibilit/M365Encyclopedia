# Digest 2026-10-29

## Copilot
- **Update: Notebooks** (Microsoft 365 Copilot, Rolling out): Web links can now be added as reference sources, and the Copilot app on iOS has a new Notebooks design with a persistent workspace for related chats, outputs and references. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
- **Copilot usage metrics for apps** (Microsoft 365 Copilot, Rolling out): The Copilot Dashboard and Viva Insights Advanced Analysis show new usage metrics for the Copilot app, Edge, OneNote, Outlook, Word, Excel and PowerPoint. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
- **Work IQ API declarative agent access** (Microsoft 365 Copilot, Rolling out): Developers can reach first-party and tenant-defined declarative agents programmatically through the Work IQ endpoint. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/work-iq/)
- **Rich entity cards for connector results** (Microsoft 365 Copilot, Rolling out): Copilot connector results in Search show as entity cards with metadata instead of plain links. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
- **Update: Multimodal capture in Notebooks** (OneNote, Rolling out): Combining audio transcription, images and typed notes in one session, already on iPhone and iPad, is now on Android. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

## Teams
- **Copilot Chat after a call in Queues** (Teams, Rolling out): In the Recap tab of a recorded call queue call, Copilot Chat can summarize the call and answer questions. Windows and Mac. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
