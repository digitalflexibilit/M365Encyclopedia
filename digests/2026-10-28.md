# Digest 2026-10-28

## Copilot
- **Custom MCP connectors** (Microsoft 365 Copilot, Rolling out): Admins can create connectors to their own MCP servers in the Microsoft 365 admin center and deploy them organization-wide, so Copilot can use internal data. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/connectors/set-up-custom-federated-connectors)
- **Work IQ API usage-based billing** (Microsoft 365 Copilot, Rolling out): Developers can call Work IQ endpoints without pre-assigned licenses. Billing is per request in Copilot Credits. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/work-iq/)
- **Learning agent** (Microsoft 365 Copilot, Rolling out): New agent for personalized microlearning and structured learning paths in Copilot. [More info](https://learn.microsoft.com/en-us/viva/learning/learning-agent-overview)
- **Attach a deck or image** (PowerPoint, Rolling out): When creating a presentation with Copilot, users can attach a deck to reuse its theme and styles, or attach an image to include in the slides. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
- **Copilot settings in classic Outlook** (Outlook, Rolling out): Copilot settings are now under File, Copilot settings in classic Outlook for Windows. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
- **Canva connector in Researcher** (Microsoft 365 Copilot, Rolling out): Researcher can include Canva content in research tasks where the connector is available. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
