# Digest 2026-11-04

## Power BI
- **Custom visuals in the Power BI Report skill** (Power BI, GA): The Power BI Report skill in Skills for Fabric can add supported custom visuals, bind them to report data, apply formatting and validate the result. [More info](https://learn.microsoft.com/en-us/power-bi/developer/agentic/power-bi-report-skill-overview)
- **Gantt chart visual** (Power BI, Preview): New core visual that shows task durations, progress and milestones on a time axis. Enable it under Preview features in Power BI Desktop. [More info](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-gantt)
- **List slicer dropdown mode** (Power BI, Preview): List slicers can show as a dropdown with dismissible selection pills, and "Show selected first" pins active selections to the top. [More info](https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-list-slicer)
