# Digest 2026-11-03

## Copilot
- **Cowork projects** (Microsoft 365 Copilot, Rolling out): Users can group related Cowork tasks, instructions and context in a project and review the files those tasks produced. Users can also reference past chats and tasks in a prompt. [More info](https://learn.microsoft.com/en-us/copilot/cowork/whats-new)
- **Cowork event-driven triggers for non-Microsoft connectors** (Microsoft 365 Copilot, Rolling out): Cowork tasks can start from events in supported non-Microsoft connectors and plugins, and Power Platform and Copilot connectors reach more external data sources. [More info](https://learn.microsoft.com/en-us/copilot/cowork/whats-new)

## Planner
- **Planner Plugin for Copilot Cowork** (Planner, Rolling out): Connects Planner to Cowork so users can list tasks, build plan reports, turn notes or documents into plans and update tasks after approval. Needs a Microsoft 365 Copilot license, Cowork access and admin enablement. [More info](https://support.microsoft.com/planner/planner-plugin-overview)
