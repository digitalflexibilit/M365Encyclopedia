# Digest 2026-11-14

## Copilot
- **Update: Business Apps in Work IQ in Copilot Cowork** (Microsoft 365 Copilot, Roadmap): A new roadmap item adds access to business applications through Work IQ from Copilot Cowork, with business skills to complete business processes. Planned for December 2026. The Work IQ business apps preview was reported on 31 October. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=573293)
- **Business skills in Work IQ MCP** (Microsoft 365 Copilot, Roadmap): Organizations write their processes, rules and domain knowledge as plain-language business skills, and agents find and follow them at runtime through the Work IQ MCP server. Planned for November 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=573290)
- **Copilot Studio MCP** (Copilot Studio, GA): MCP-compatible tools such as Visual Studio Code and GitHub Copilot CLI can use the @microsoft/copilot-studio-mcp package to create, test, deploy and monitor agents and workflows without opening Copilot Studio. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/copilot-studio-mcp)
- **Upgrade agents to the Microsoft Copilot harness** (Copilot Studio, Preview): Copilot Studio moves an agent from the standard harness, carries over instructions, tools and prompts, rebuilds topics as skills or workflows and produces a migration report. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/upgrade-to-github-copilot-from-standard-harness)
- **Shared skills marketplace** (Copilot Studio, Preview): Makers can add skills shared by admins or colleagues and share their own skills with people, groups or the whole organization, with update notifications. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/skills-manage)
- **Privacy statement link for agents** (Copilot Studio, Preview): Admins set a privacy policy link per environment that is shown at the start of agent conversations on the standard harness. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/configure-privacy-statement-link)
- **WhatsApp channel through Azure Communication Services** (Copilot Studio, Retiring): Since 23 October 2026 agents can no longer be newly connected to WhatsApp through this channel. Agents connected before that date keep working. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/publication-add-bot-to-whatsapp)
- **Facilitator follow-up mode** (Teams, Roadmap): Users can keep chatting with Facilitator in a meeting without @mentioning it each time. Planned for December 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=566523)

## Teams
- **Impersonation protection for meetings** (Teams, Rolling out): Teams warns users and shows risk indicators when a participant or organizer may be impersonating someone. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=573157)
- **Phishing detection in Teams chats** (Teams, Rolling out): AI-based detection uses conversation context to flag phishing and social engineering, mainly in first-contact chats with external people. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=575288)
- **Granular Conditional Access for meetings** (Teams, Rolling out): Admins can apply Conditional Access policies to selected meetings, so participants must meet the requirements before joining. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=571879)
- **Automatic recording and transcription choices follow policy** (Teams, Rolling out): Meeting options only show the automatic recording and transcription choices that policy allows, and a new "Record only" choice records without transcribing. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=570468)
- **Policy control over who can record and transcribe** (Teams, Roadmap): Meeting policies will set whether only organizers and co-organizers, or presenters too, can start recording and transcription, and whether organizers can change this. Planned for December 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579860)
- **Alternative text for images from OneDrive and SharePoint** (Teams, Rolling out): Users can add alt text to images they share in Teams from OneDrive and SharePoint. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=571687)
- **Two presenters sharing at the same time** (Teams, Roadmap): Two presenters can share a screen or window at once in a meeting. The roadmap date moved to January 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=80239)

## Outlook
- **Folder sharing follows organization policy** (Outlook, Roadmap): In new Outlook for Windows, users cannot change Default and Anonymous folder permissions when the organization restricts them. Permissions for named users are not affected. Planned for January 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579185)

## Power Apps
- **AI-generated descriptions for canvas apps** (Power Apps, Retiring): After 30 November 2026 the "Create descriptions using AI" option is also removed for canvas apps. Existing descriptions stay. [More info](https://learn.microsoft.com/en-us/power-platform/important-changes-coming)
- **Calendar and card view layouts in model-driven apps** (Power Apps, Roadmap): Makers can show views as a calendar or a stack of cards instead of a grid, set in the app designer. Preview planned for December 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=575294)
- **Modernized Personal settings in model-driven apps** (Power Apps, Roadmap): A redesigned Personal settings page, on by default, with a button to return to the classic page. Planned for December 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579899)

## Power Automate
- **Copilot in the designer for cloud and agent flows** (Power Automate, Retiring): The Copilot pane in the flow designer is retired on 30 November 2026. Existing flows are not changed, and Microsoft points to the Power Automate plugin in an approved AI assistant such as GitHub Copilot. [More info](https://learn.microsoft.com/en-us/power-platform/important-changes-coming)
- **Direct triggers for desktop flows** (Power Automate, Roadmap): Desktop flows will start on supported events without an intermediate cloud flow. Preview planned for January 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579975)

## Dataverse
- **Column-based record security** (Dataverse, Roadmap): Admins can secure records by column values such as region or department instead of ownership. GA planned for January 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=577860)

## Admin and governance
- **Cross-tenant orchestrated migration** (Microsoft 365 admin center, Roadmap): Admins can move mailboxes, OneDrive, Teams chats and meetings, groups, SharePoint sites and teams from one tenant to another. Planned for December 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=576273)
