# Digest 2026-11-23

## Planner
- **Unified plans** (Planner, GA): Microsoft confirmed that personal tasks, basic plans and premium features now share one unified plan type, with features depending on each user's license. New features ship only to unified plans, conditional coloring in Grid view and task history are rolling out, and premium plans stay supported on Dataverse during the transition. [More info](https://learn.microsoft.com/planner/planner-for-admins)

## Other Microsoft 365 apps
- **Microsoft To Do apps** (To Do, Retiring): The To Do apps are scheduled to retire on June 30, 2027. New private tasks go to a private plan in Planner, existing To Do tasks are visible in Planner but not migrated, and personal Microsoft account users need another app. [More info](https://techcommunity.microsoft.com/blog/plannerblog/introducing-unified-tasks-and-plans-for-copilot-and-microsoft-365/4573958)
- **Access form controls with rounded corners** (Access, Preview): A new Corner Radius property rounds the corners of ten form control types, set in the property sheet or with VBA. Available in Beta Channel 2612 and Current Channel (Preview) 2611. [More info](https://techcommunity.microsoft.com/blog/accessblog/give-your-access-forms-a-fresh-look-with-rounded-corners/4573058)
