# Digest 2026-10-31

## Copilot
- **Work IQ MCP server in Copilot Studio** (Copilot Studio, Preview): Agents can use the Work IQ MCP server to work with business context from Dynamics 365 and Power Apps. Announced at PPCC 2026. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/add-work-iq)
- **Business Apps in Work IQ** (Microsoft 365 Copilot, Preview): Brings business context from Dynamics 365 and Power Apps into Copilot and agents, with governed actions. [More info](https://learn.microsoft.com/en-us/power-apps/maker/data-platform/business-applications-work-iq)

## SharePoint
- **SharePoint HTML pages with Copilot** (SharePoint, Preview): Authors can create an HTML page with Copilot or upload their own HTML to the Site Pages library, then edit, publish and share it next to ASPX pages. General availability is planned from mid-November to late December 2026. Creating or editing with Copilot needs a Microsoft 365 Copilot license. [More info](https://support.microsoft.com/en-us/sharepoint/create-edit-publish-html-pages)

## Dataverse
- **Dataverse Ask API** (Dataverse, Preview): Lets developers define semantic models and ask natural-language questions through the Web API or the Dataverse connector. [More info](https://learn.microsoft.com/en-us/power-apps/developer/data-platform/ask/)
