# Digest 2026-11-15

## Copilot
- **Continue using retired models** (Copilot Studio, GA): After Copilot Studio upgrades an agent's default model, makers can keep the agent on the retired model for up to 30 days and switch between the old and new model while they test. The setting is per agent under Settings, Model. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-retired-model)
- **Connected agents from Foundry, the Agents SDK and A2A** (Copilot Studio, Preview): Agents on the Microsoft Copilot harness can now delegate tasks to Microsoft Foundry agents and Microsoft 365 Agents SDK agents, in addition to other Copilot Studio agents. Remote agents over the Agent2Agent (A2A) protocol can also be connected, in preview. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/authoring-add-other-agents)
- **Facilitator answers open questions** (Teams, Roadmap): When a question in a meeting goes unanswered, Facilitator offers to find the answer with web search and posts it if a participant agrees. Planned for February 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=558341)
- **Updated Copilot Chat sheet in Outlook mobile** (Outlook, Roadmap): Copilot Chat in Outlook for iOS and Android gets smoother animations and a simpler header, with the new and temporary chat button moved behind the "..." menu. Planned for December 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579897)

## Teams
- **Real-time queue metrics in the Queues app on mobile** (Teams, Roadmap): Call queue agents and supervisors can see live queue metrics in the Queues app on iOS and Android. Planned for December 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579859)
- **Express face enrollment** (Teams, Roadmap): Users who opt in can create a face profile with their camera during eligible meetings, so Teams Rooms can recognize them for recaps and Copilot. Admins can turn it on or off. Planned for February 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=570846)

## Outlook
- **Recoverable items storage usage** (Outlook, Roadmap): New Outlook for Windows and Outlook on the web will show how much mailbox storage recoverable items use. Planned for February 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579190)
- **Sort subfolders from A to Z** (Outlook, Roadmap): Users can sort a folder's subfolders alphabetically in one step from the parent folder. Planned for February 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579186)
- **Folder pane remembers expanded folders** (Outlook, Roadmap): Outlook keeps folders, shared mailboxes and the online archive expanded or collapsed after a restart, and adds an option to expand or collapse all accounts at once. Planned for February 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579187)

## Power Apps
- **Responsive SharePoint list form template** (Power Apps, Rolling out): New customized SharePoint list forms use a flexible canvas with a multi-column layout that adapts to the available width, instead of a single-column phone-sized form. Existing forms keep their layout. [More info](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/sharepoint-form-integration)
- **Updated template for apps created from SharePoint lists** (Power Apps, Rolling out): Apps generated from a SharePoint list get a responsive records screen with grid and list views built on the modern Data Grid and modern forms, plus separate screens for new and edited items. [More info](https://learn.microsoft.com/en-us/power-apps/maker/canvas-apps/app-from-sharepoint)

## Power Automate
- **Delinea Secret Server credentials for desktop flows** (Power Automate, Roadmap): Desktop flows will be able to use credentials stored in Delinea Secret Server for machine sign-in and credential retrieval in attended and unattended runs. Planned for March 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579974)

## Power BI
- **R and Python visuals** (Power BI, Retiring): R and Python visuals, including R-powered custom visuals, retire in May 2027. After that they stop working in published reports and new Power BI Desktop versions no longer include them. Python and R scripts in Power Query are not affected. [More info](https://learn.microsoft.com/en-us/power-bi/create-reports/script-visuals-overview#retirement-of-r-and-python-visuals)

## Admin and governance
- **Low-latency Monitor alerts** (Power Platform admin center, Preview): Admins can set an alert rule's data review period to 1 hour, so Monitor checks app, cloud flow and agent metrics every hour instead of once a day. Up to 10 hourly rules per admin center. Public preview in all commercial clouds by 20 November 2026. [More info](https://learn.microsoft.com/en-us/power-platform/admin/monitoring/alerts#monitor-critical-resources-with-low-latency-alerts-preview)
- **Monitor metrics export API** (Power Platform admin center, Preview): A REST API returns Monitor's daily metric aggregates in OpenTelemetry (OTLP JSON) format, so admins can keep them beyond the 30-day retention or load them into tools such as Datadog or Splunk. [More info](https://learn.microsoft.com/en-us/power-platform/admin/monitoring/monitor-data-export)
- **Expanded DLP enforcement in Edge for Business** (Microsoft Edge, Roadmap): Admins can apply Data Loss Prevention connector enforcement more consistently to download, upload, paste and print, with required bypass justification and custom guidance for users. Planned for December 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=579894)
