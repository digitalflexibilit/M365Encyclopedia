# Digest 2026-11-12

## Copilot
- **App Blocks** (Microsoft 365 Copilot Chat, Rolling out): Copilot Chat can turn a request and its data into an interactive element in the conversation, such as a calculator, dashboard, form or comparison tool, where users change inputs and see the result in place. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=577743)
- **Update: Work IQ in Copilot Studio** (Copilot Studio, GA): Work IQ is now generally available and added by default to every new agent on the GitHub Copilot harness, with all workloads selected and write operations on by default. The Business apps workload with Dynamics 365 and Power Apps context, reported on 31 October, stays in preview. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/add-work-iq)
- **Customer Conversation harness** (Copilot Studio, Preview): A new harness for customer-facing agents over voice and chat, with sub-agents that can escalate unresolved issues to a human representative. Agents can be published on a website or get a phone number, and usage is billed in Copilot Credits. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/overview-customer-conversation)
- **Agent accounts** (Copilot Studio, Preview): Makers can give an agent its own Entra account, mailbox and Teams presence, so people email and @mention it like a colleague and it keeps one shared memory for the team. Frontier preview that needs an early release environment and a Microsoft 365 Frontier for AI Teammates license per agent. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/authoring-agent-account)
- **Triggers for autonomous agents** (Copilot Studio, Preview): Agents on the GitHub Copilot harness can run on their own when an event happens, such as a new SharePoint item, an incoming email or a schedule, and can be shared so others run them with their own credentials. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/authoring-add-event-trigger)
- **MCP and A2A client channels** (Copilot Studio, Preview): A published agent can be exposed as a remote MCP server or an A2A agent for IDEs, tools and other orchestrators, with Entra ID sign-in. Early release cycle environments only. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/publication-channels-mcp-agent-to-agent)
- **Knowledge source controls for agents** (Copilot Studio, GA): Admins can separately allow or block uploaded documents, SharePoint and OneDrive, and public websites as agent knowledge sources in the Power Platform admin center. [More info](https://learn.microsoft.com/en-us/microsoft-copilot-studio/choose-knowledge-sources)
- **Intelligent recap without saving the transcript** (Teams, GA): Organizers can get the AI summary of a meeting without keeping the transcript afterward. Chapters, topics, mentions and audio recap may not be available. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=558286)
- **Ask Copilot from Search on mobile** (Teams, Rolling out): The Teams mobile search bar offers an option to ask Copilot next to the search results and to continue the query as a Copilot conversation. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=571299)
- **Update: Planner Agent status reports** (Planner, Rolling out): Planner Agent can now write a status report from plan data covering status, progress, risks and next steps, with a chosen audience, tone and length. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=567886)

## Teams
- **Personal message reminders** (Teams, Rolling out): Users set private reminders on chat and channel messages, track them in a Reminders view and get notified when they are due. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=565869)
- **Facilitator scam alerts** (Teams, Rolling out): Facilitator's Protection skill checks the meeting transcript for social engineering by outside participants and shows a warning with options to end the meeting or restrict information sharing. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=573450)
- **Default meeting templates** (Teams, Rolling out): Admins set meeting settings, including protection settings, that apply automatically to meetings scheduled from Outlook or the Teams calendar. Organizers need Teams Premium. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=576609)
- **Pinch to zoom on shared screens** (Teams, Rolling out): Users can zoom in on shared content in calls and meetings with a touchpad pinch. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=576193)
- **SharePoint app in Teams opens page links** (Teams, Rolling out): On mobile, SharePoint page and news links in chats and channels open in the SharePoint app in Teams instead of the browser. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=567314)

## SharePoint
- **Permission report for a group** (SharePoint, Rolling out): A data access governance report in the SharePoint admin center lists every site a given group can access and how much access it has. The rollout moved from June to November 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=561039)

## Admin and governance
- **DLP for Copilot Cowork** (Microsoft Purview, GA): The Purview DLP policy location for Copilot and Copilot Chat now covers Cowork, so one policy can block labeled content, prompts with sensitive information types and web searches with such prompts. Blocking external email is not yet supported for Cowork. [More info](https://learn.microsoft.com/purview/dlp-microsoft365-copilot-location-learn-about)
