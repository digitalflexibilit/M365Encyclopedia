# Digest 2026-11-27

## Copilot
- **Update: Copilot memory** (Microsoft 365 Copilot, Rolling out): The Microsoft 365 Roadmap item for Copilot memory in Researcher was cancelled on 26 November and will be removed. Memory in Word, Excel, PowerPoint, Workspaces and OneNote is still listed for November 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=562996)
- **Workforce requests in Microsoft 365 Copilot** (Microsoft 365 Copilot / Dynamics 365 Customer Service, GA): Supervisors can list, review and approve or reject time-off, shift-swap and shift-bid requests from Dynamics 365 Workforce Engagement Management in Microsoft 365 Copilot through MCP tools. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=581992)

## Teams
- **Meeting timers in Teams Rooms on Windows** (Teams, Roadmap): A shared countdown timer controlled from the room console, shown on the room display and in participants' meeting views. Requires Teams Rooms Pro, planned for January 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=581893)
- **Improved device settings on Teams Rooms on Android** (Teams, Roadmap): Clearer structure and navigation for on-device admin settings. Planned for January 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=581965)
- **PowerPoint Live in webinars and structured meetings on Teams Rooms on Android** (Teams, GA): Room participants can view and interact with PowerPoint Live presentations in webinars and structured meetings. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=576195)

## SharePoint
- **FAQ web part authoring changes** (SharePoint, GA): The FAQ web part is now a manual, non-AI editor. AI-assisted FAQ creation and import moves to Copilot in SharePoint authoring; existing FAQ web parts keep working. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=570647)

## Planner
- **Capacity view** (Planner, GA): A timeline of who is working on what, to spot overloaded team members and open capacity. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=569733)

## Other Microsoft 365 apps
- **Viva Glint bulk participant removal** (Viva Glint, Roadmap): Admins can remove any number of participants from a closed survey by file upload instead of 25 at a time; responses are deleted and the action is audited. General availability planned for December 2026. [More info](https://techcommunity.microsoft.com/blog/viva_glint_blog/news-to-know-%E2%80%93-volume-3-edition-12-november-2026/4576732)

## Admin & governance
- **Auto-expanding archive up to 3 TB** (Microsoft Purview / Exchange Online, GA): Auto-expanding archives for mailboxes with eligible E5-level licenses can now grow to 3 TB instead of stopping at 1.5 TB, with no extra configuration or charge. [More info](https://learn.microsoft.com/purview/enable-autoexpanding-archiving)
- **Auto-labeling coverage report** (Microsoft Purview, Rolling out): For each enforced auto-labeling policy on SharePoint or OneDrive, admins see which files were labeled, pending or not labeled, compared with the latest simulation run. [More info](https://learn.microsoft.com/purview/apply-sensitivity-label-automatically)
- **Auto-labeling for legacy Office files** (Microsoft Purview, Roadmap): Server-side auto-labeling will support .doc, .xls and .ppt files in SharePoint and OneDrive. Planned for December 2026. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=574363)
- **Version trimming for content under retention** (Microsoft Purview, Roadmap): A policy-scoped setting will let SharePoint trim file versions in OneDrive and SharePoint even when retention policies apply, except for protected cases such as holds and records. Planned for January 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=575284)
- **Network DLP for all websites through Global Secure Access** (Microsoft Purview, Roadmap): Network data security DLP policies integrated with Entra Global Secure Access can be scoped to all websites, or all except specific cloud apps. Planned for March 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=575285)
- **Endpoint DLP policy sync status within 30 minutes** (Microsoft Purview, Rolling out): The Purview portal shows Endpoint DLP policy sync status within 30 minutes instead of 2 hours. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=558682)
- **High Volume Email for external recipients** (Exchange Online, Roadmap): HVE will be able to send transactional mail such as alerts and receipts to external recipients, turned on per HVE account and billed per external recipient. Planned for March 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=581778)
- **Unified finance and operations user and role management** (Power Platform admin center, Roadmap): Admins will manage system administrator users and security roles for finance and operations apps and Dataverse from one page. General availability planned for January 2027. [More info](https://www.microsoft.com/microsoft-365/roadmap?filters=&searchterms=581777)
