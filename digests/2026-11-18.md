# Digest 2026-11-18

## Copilot
- **Update: Office in Copilot** (Microsoft 365 Copilot, GA): Word, Excel and PowerPoint in the Copilot app moved from Frontier rollout to general availability in Chat and Cowork. Files save to OneDrive with existing permissions, labels and compliance controls, with no metered usage for creating decks or spreadsheets. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/home-your-starting-place-for-work-in-the-microsoft-copilot-app/4573945)
- **Update: Home with Chat and Cowork** (Microsoft 365 Copilot, GA): Chat and Cowork in Home are now generally available, and Home is rolling out worldwide. Projects and Automations are also generally available. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/home-your-starting-place-for-work-in-the-microsoft-copilot-app/4573945)
- **Update: Copilot Managed Runtime** (Microsoft 365 Copilot, GA): Hosting for apps built in Copilot Code, Cowork, Copilot Studio and developer tools moved from preview to general availability. Fabric as a storage backend is in Frontier preview. [More info](https://techcommunity.microsoft.com/blog/copilot-managed-runtime-blog/copilot-managed-runtime-is-now-generally-available-with-additional-new-preview-f/4571846)
- **Update: Autopilot** (Microsoft 365 Copilot, Preview): Autopilot moved from private preview to a rollout for Frontier program customers. Colleagues can @mention a person's Autopilot in Teams channels and group chats. [More info](https://learn.microsoft.com/en-us/copilot/autopilot/overview)
- **Update: Copilot Code** (Microsoft 365 Copilot, Preview): General availability is now planned for December 2026. It is in Frontier on Windows, web, iOS and Android, with a local sandbox on Windows. [More info](https://learn.microsoft.com/en-us/copilot/code/use-code)
- **Today** (Microsoft 365 Copilot, Preview): A new view in the Copilot app and Outlook that surfaces priorities across mail, calendar, Teams, meetings and Cowork tasks and prepares drafts for approval. Private preview in Frontier. Today Brief is included with a Copilot license, and Today Feed uses Copilot Credits. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/home-your-starting-place-for-work-in-the-microsoft-copilot-app/4573945)
- **Auto model routing** (Microsoft 365 Copilot, Preview): Auto picks the model and effort level per task, and in Cowork splits large tasks across parallel subagents. Auto in Cowork is rolling out to Frontier, and chat-to-Cowork recommendations are generally available. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/home-your-starting-place-for-work-in-the-microsoft-copilot-app/4573945)
- **Salesforce in Copilot** (Copilot Cowork, Preview): A new plugin brings Salesforce account, opportunity and pipeline context into Cowork with more than 38 prebuilt sales skills. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/whats-new-in-copilot-cowork-at-ignite-2026/4572242)
- **Dynamics 365 plugins in Copilot** (Copilot Cowork, GA): The Dynamics 365 Sales plugin, expanded with skills for account briefs, pitch decks and proposals, and the ERP plugin for finance work in Cowork and Excel are generally available. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/whats-new-in-copilot-cowork-at-ignite-2026/4572242)
- **Brand Kit in Cowork** (Copilot Cowork, Rolling out): Cowork applies an organization's brand colors, fonts and voice when it builds content. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/whats-new-in-copilot-cowork-at-ignite-2026/4572242)
- **Claude Fable 5.2 model in Cowork** (Copilot Cowork, GA): Fable 5.2 is in the Cowork model selector for select customers and replaces Fable 5.1. It requires data retention by the model provider. [More info](https://learn.microsoft.com/en-us/copilot/cowork/whats-new)

## Copilot Studio
- **Local development and CLI publishing** (Copilot Studio, Preview): Makers can build agents and workflows locally with their own tools, keep them in GitHub and publish to Copilot Studio with the CLI. Public preview. [More info](https://techcommunity.microsoft.com/blog/copilot-managed-runtime-blog/copilot-managed-runtime-is-now-generally-available-with-additional-new-preview-f/4571846)

## Planner
- **Update: Planner Plugin for Copilot Cowork** (Planner, GA): The plugin that turns meeting action items into Planner tasks and creates status updates from plans is now generally available. [More info](https://support.microsoft.com/planner/planner-plugin-overview)

## Other Microsoft 365 apps
- **Viva Engage plugin for Cowork** (Viva Engage, GA): Cowork can summarize Viva Engage community conversations and draft community announcements. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/whats-new-in-copilot-cowork-at-ignite-2026/4572242)

## Admin & governance
- **Agent 365 Business Analytics** (Agent 365, Preview): A new app connects AI spend, usage and value across Microsoft and non-Microsoft AI, with forecasts and budget tracking. Rolling out in Frontier. Needs at least one Copilot license, and Agent 365 or E7 for non-Microsoft services. [More info](https://learn.microsoft.com/en-us/a365-business-analytics/overview)
- **Agent 365 usage insights for Microsoft agents** (Microsoft 365 admin center, GA): Agent overview, active users and usage metrics for Microsoft agents no longer need an Agent 365 license. Non-Microsoft agent insights and advanced governance still need Agent 365 or E7. [More info](https://techcommunity.microsoft.com/blog/agent-365-blog/whats-new-in-microsoft-agent-365-ignite-2026/4571753)
- **Plugin and skill governance** (Microsoft 365 admin center, GA): Admins control which plugins and skills are available in Copilot and Cowork per user or group, and see dependent agents before blocking an MCP server. [More info](https://learn.microsoft.com/en-us/microsoft-agent-365/admin/agent-tools-overview)
- **Baseline Security Mode 2026** (Microsoft 365 admin center, GA): New recommended security settings, now covering Intune, Purview and Dynamics 365, can be applied or simulated by a Global Administrator. Examples include a Teams lobby for external users and MFA for guests. [More info](https://techcommunity.microsoft.com/blog/microsoft_365blog/ignite%E2%80%9926-spotlight-announcing-microsoft-baseline-security-mode-2026-general-ava/4572694)
- **DLP for sensitive files in Copilot grounding** (Microsoft Purview, Preview): DLP will be able to stop Copilot from grounding on sensitive files even when they are unlabeled, and prompt protection now covers attachments and linked files. Public preview planned for January 2027. [More info](https://techcommunity.microsoft.com/blog/microsoft-security-blog/secure-the-data-that-fuels-ai-with-microsoft-purview/4573266)
