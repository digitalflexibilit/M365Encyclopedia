# Digest 2026-11-05

## Copilot
- **Copilot New Tab Page in Microsoft Edge** (Microsoft 365 Copilot, Rolling out): The refreshed new tab page combines search, chat, Copilot-suggested actions, curated work content, news and activities in one search box. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **HubSpot connector in Researcher** (Microsoft 365 Copilot, Rolling out): Researcher can now add HubSpot data to its responses. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **Navigate to workbook changes from Copilot chat** (Excel, Rolling out): Copilot chat responses link to new or changed sheets, tables, ranges and objects. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **Reference an attached deck's style** (PowerPoint, Rolling out): Update: on Windows and Mac, Copilot applies the theme and styles of an attached deck to a new presentation. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **Account selector in the Copilot side pane** (Outlook, Rolling out): New Outlook shows an account dropdown in the Calendar Copilot side pane when several Copilot-enabled accounts are added. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **AI Workflows in the Workflows app** (Teams, Rolling out): Copilot-powered scheduled prompt templates are available on Windows and Mac. Off by default unless admins enable the Workflows app. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **SharePoint list agent** (SharePoint, Rolling out): Creates Microsoft Lists from natural-language prompts, including the schema. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)

## Admin and governance
- **Agents usage report** (Microsoft 365 admin center, Rolling out): Shows active agent users and agents for Microsoft 365 Copilot and Copilot Chat, by license type and publisher. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **Authoritative content management for Copilot Search** (Microsoft 365 admin center, Rolling out): Admins can designate up to 100 SharePoint sites as authoritative, with bulk import and export. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
