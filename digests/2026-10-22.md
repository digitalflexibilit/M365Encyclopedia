# Digest 2026-10-22

## Copilot
- **Seamless Search and Chat** (Microsoft 365 Copilot, Rolling out): Microsoft 365 Chat is now embedded in Copilot Search results on Windows and web, so users can ask follow-up questions in the same view. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
- **Custom skills** (PowerPoint, Rolling out): Users can create personal commands and workflows with Create custom skill in the Copilot pane, now on Windows after web in September. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
- **Reference SharePoint and OneDrive files** (PowerPoint, Rolling out): On Mac, Copilot recognizes files in SharePoint and OneDrive named in a prompt when creating a presentation. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)
- **Copilot connector rules** (Admin, Rolling out): Admins can edit query string and user identity mapping rules after a connector is created, without a support ticket. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)

## Power Platform
- **Managed developer environments only** (Admin, Retiring): From 15 November 2026 only managed developer environments can be created, one per user. Unmanaged ones are suspended on 15 December 2026 and deleted on 15 January 2027. [More info](https://learn.microsoft.com/en-us/power-platform/important-changes-coming)
- **Dataverse for Teams environments** (Dataverse, Retiring): New environments cannot be created from 15 November 2026. Environments not upgraded are suspended on 15 September 2027 and decommissioned on 30 October 2027. [More info](https://learn.microsoft.com/en-us/power-platform/important-changes-coming)
