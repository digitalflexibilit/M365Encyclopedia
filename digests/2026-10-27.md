# Digest 2026-10-27

## Copilot
- **Frontier program expands** (Microsoft 365 Copilot, Preview): From November 2026 the Frontier program includes eligible public preview features for new Outlook for Windows, OneDrive, SharePoint and Teams. A license that includes access to the app is needed. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/frontier-expands-to-more-microsoft-365-public-previews/4567243)

## Microsoft 365 apps
- **GitHub app in Teams** (Teams, GA): The new app brings GitHub notifications and GitHub Copilot into Teams. The legacy app is renamed "GitHub (deprecated)" and retired on 16 November 2026. [More info](https://techcommunity.microsoft.com/blog/microsoftteamsblog/turn-github-notifications-into-code-with-github-copilot-in-microsoft-teams/4566408)
