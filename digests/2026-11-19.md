# Digest 2026-11-19

## Copilot
- **Tableau Copilot connector** (Microsoft 365 Copilot, Rolling out): Users can ask Copilot about Tableau dashboards and visualizations, with Tableau permissions still applied. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **Confluence Cloud connector query filters** (Microsoft 365 Copilot, Rolling out): Admins can include or exclude Confluence spaces and use CQL strings to limit which pages the connector syncs. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **Work IQ plugin for ChatGPT** (Microsoft 365 Copilot, GA): A Work IQ plugin in the ChatGPT plugin directory brings Microsoft 365 work context into ChatGPT Business and Enterprise. A plugin for Anthropic is announced as coming soon. [More info](https://techcommunity.microsoft.com/blog/microsoft_365blog/whats-new-in-work-iq-at-ignite-2026-agents-that-get-work-done/4572219)
- **Custom engine agents in Outlook** (Outlook, Rolling out): Users can run custom engine agents from the agent pane in Outlook on the web to automate email tasks such as sorting or summarizing. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **Copilot turns notes into Office drafts** (OneNote, Preview): Copilot in OneNote can turn notes into a first-draft Word document, an Excel timeline or a PowerPoint proposal. Frontier public preview. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/office-at-ignite-2026-from-apps-to-agentic-system-of-work/4572226)
- **SharePoint tools in Work IQ** (SharePoint, Preview): Copilot and agents get more than 60 SharePoint operations for lists, libraries, files, approvals and version history through Work IQ, with the WorkIQ.Read or WorkIQ.Act permission. Billed in Copilot Credits. [More info](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/work-iq/sharepoint-iq)

## Copilot Studio
- **Update: Apps in Copilot Studio** (Copilot Studio, GA): App creation moved from public preview to general availability and runs on Copilot Managed Runtime. [More info](https://www.microsoft.com/en-us/dynamics-365/blog/business-leader/2026/11/17/microsoft-ignite-2026-introducing-dynamics-365-in-copilot/)
- **Agent node in workflows** (Copilot Studio, Rolling out): An agent node lets one workflow step reason over data, call tools and return a response. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)

## Teams
- **Express voice enrollment** (Teams, Rolling out): Users can opt in to create a voice profile from audio captured in their meetings, from the Recognition tab in settings. Admins can turn it on or off. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **Custom recording and transcription notifications for calls** (Teams, Rolling out): Admins can customize part of the notification text shown when a call is recorded or transcribed. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)

## Outlook
- **Message list sort improvements** (Outlook, Rolling out): On Windows, sorting by a field other than From, Subject or Date Received shows a column with the sort value, and sorting by Flag Due Date is supported. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)

## Power BI
- **Standalone Power BI Copilot** (Power BI, Retiring): Standalone Copilot on the web, in Teams and in mobile is planned to end by the end of January 2027. Copilot inside reports stays. [More info](https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new)
- **App-scoped Copilot** (Power BI, Retiring): App-scoped Copilot in workspace apps and its setting will be removed in January 2027. [More info](https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new)
- **Visual style presets** (Power BI, GA): Save visual formatting as reusable presets, set a default and distribute presets through report themes. [More info](https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new)
- **Update: List slicer dropdown mode** (Power BI, GA): List slicer dropdowns, selection pills and multi-line selection display moved from preview to general availability. [More info](https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new)
- **Power BI integration with OneDrive and SharePoint** (Power BI, GA): View PBIX files in the browser and open, save and share them from Desktop with OneDrive and SharePoint. [More info](https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new)
- **Embed workspace apps in SharePoint Online** (Power BI, GA): A whole workspace app, with navigation and sections, can be embedded in a SharePoint page. [More info](https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new)
- **Semantic views** (Power BI, Preview): Define tables, relationships and shared metrics in a semantic view that publishes as a read-only Direct Lake on OneLake semantic model. [More info](https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new)
- **Power BI Desktop for Apps** (Power BI, Preview): An upcoming Desktop experience to build interactive Fabric apps from a semantic model with AI-assisted authoring. [More info](https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new)
- **Card visual trend charts** (Power BI, Preview): A Trend axis adds a trend chart to card visuals. [More info](https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new)

## Admin & governance
- **Share custom organizational attributes with people experiences** (Microsoft 365 admin center, Rolling out): Admins can share custom attributes from Organizational Data Service with the Microsoft 365 people store. Off by default, and shared attributes are visible to all users and guests. [More info](https://learn.microsoft.com/en-us/copilot/microsoft-365/release-notes)
- **Auto-labeling scalability improvements** (Microsoft Purview, GA): Auto-labeling now handles up to 500,000 SharePoint and OneDrive files per tenant per day, up from 100,000, with simulation for up to 20 million items. [More info](https://techcommunity.microsoft.com/blog/microsoft-security-blog/secure-the-data-that-fuels-ai-with-microsoft-purview/4573266)
- **Default library labels for existing files** (Microsoft Purview, Preview): A SharePoint library's default sensitivity label can now be applied to files already in it without opening them. [More info](https://techcommunity.microsoft.com/blog/microsoft-security-blog/secure-the-data-that-fuels-ai-with-microsoft-purview/4573266)
- **DLP for local AI agents on Windows** (Microsoft Purview, Roadmap): Purview will show the activity of local agents such as Claude Code, GitHub CLI and Claude Desktop, and DLP can block prompts and tool calls with sensitive data. Public preview planned for January 2027. [More info](https://techcommunity.microsoft.com/blog/microsoft-security-blog/secure-the-data-that-fuels-ai-with-microsoft-purview/4573266)
