# Digest 2026-11-20

## Copilot
- **Copilot Pages** (Microsoft 365 Copilot, Preview): Copilot turns a prompt and source material into an interactive report, brief, dashboard or animation, with agents keeping the data up to date. Frontier public preview, announced at Ignite on 17 November. [More info](https://techcommunity.microsoft.com/blog/microsoft-copilot-blog/office-at-ignite-2026-from-apps-to-agentic-system-of-work/4572226)
- **Declarative agents in Copilot Cowork** (Copilot Cowork, Preview): Cowork can suggest tasks for and call declarative agents an organization has built. Private preview through the Frontier program. [More info](https://news.microsoft.com/events/ignite/2026/book-of-news/)
- **Work IQ listen capability** (Microsoft 365 Copilot, Preview): Agents using Work IQ can act on events such as new messages or business events without a person starting the conversation or polling for updates. [More info](https://techcommunity.microsoft.com/blog/microsoft_365blog/whats-new-in-work-iq-at-ignite-2026-agents-that-get-work-done/4572219)
- **Microsoft Copilot harness** (Copilot Studio, GA): The harness for reasoning-heavy agents and workflows, which plans steps, calls tools and connected agents, and creates Word, Excel, PowerPoint and PDF files, is now generally available. Usage is billed in Copilot Credits. [More info](https://learn.microsoft.com/microsoft-copilot-studio/harnesses-overview)
- **Windows 365 for Agents in the Microsoft Copilot harness** (Copilot Studio, Roadmap): Agents can already use a Windows 365 Cloud PC as a computer-use tool in the standard harness; a preview for the Microsoft Copilot harness starts in December 2026. Windows 365 for Agents also becomes eligible for Copilot Credits. [More info](https://techcommunity.microsoft.com/blog/windows-itpro-blog/windows-365-at-ignite-2026-introducing-new-cloud-pc-capabilities-for-people-agen/4570006)
- **Fabric IQ in Excel** (Excel, Preview): Edit with Copilot in Excel can query governed Power BI semantic models and create live PivotTables connected to Fabric. [More info](https://azure.microsoft.com/en-us/blog/introducing-the-new-microsoft-iq-putting-your-organizations-intelligence-to-work-in-every-agent)
- **Fabric IQ connectors for ChatGPT and Claude** (Power BI, Preview): Users can query Power BI semantic models from ChatGPT and Claude through Fabric IQ connectors. [More info](https://azure.microsoft.com/en-us/blog/introducing-the-new-microsoft-iq-putting-your-organizations-intelligence-to-work-in-every-agent)

## Other Microsoft 365 apps
- **Communities in Teams** (Viva Engage, GA): Employees can find and take part in Viva Engage communities inside Teams. Further work on navigation, mobile, notifications and discovery is planned. [More info](https://techcommunity.microsoft.com/blog/Viva_Engage_Blog/from-conversations-to-intelligence-whats-new-for-viva-engage-at-microsoft-ignite/4572999)
- **Agent insights in Viva Insights without an Agent 365 license** (Viva Insights, Roadmap): Eligible organizations no longer need an Agent 365 license for agent insights, but still need at least 50 Microsoft 365 Copilot licenses. [More info](https://techcommunity.microsoft.com/blog/agent-365-blog/whats-new-in-microsoft-agent-365-ignite-2026/4571753)

## Admin & governance
- **Shadow AI in the Microsoft 365 admin center** (Agent 365, Preview): A new page lists unmanaged AI apps and agents found on devices, such as ChatGPT Desktop, Claude Desktop, Ollama and OpenClaw, and can block OpenClaw on Intune-managed Windows devices. Frontier preview, needs Defender for Endpoint, Intune and Microsoft 365 E5. [More info](https://learn.microsoft.com/en-us/microsoft-agent-365/admin/agent-shadow-ai)
- **Agent use case classification** (Agent 365, Preview): Agent sessions and Cowork activity are classified into a built-in taxonomy of use cases, shown in Agent Map and on each agent. On by default, for Frontier tenants with at least 50 Copilot licenses. [More info](https://learn.microsoft.com/microsoft-agent-365/admin/business-use-case-for-agents)
- **Work IQ enterprise controls** (Microsoft 365 admin center, Preview): Admins can set a tenant-wide ceiling for agent actions, and separate WorkIQ.Read and WorkIQ.Act permissions let policies allow, block or require approval for actions. [More info](https://techcommunity.microsoft.com/blog/microsoft_365blog/whats-new-in-work-iq-at-ignite-2026-agents-that-get-work-done/4572219)
- **Dynamic agent risk** (Agent 365, Preview): Each agent gets one continuously updated risk level from identity, access, data and activity signals, shared across the Microsoft 365 admin center, Defender, Entra and Purview. [More info](https://techcommunity.microsoft.com/blog/agent-365-blog/whats-new-in-microsoft-agent-365-ignite-2026/4571753)
- **Multi-tenant agent management** (Agent 365, Preview): Partners and multi-tenant organizations get one view to deploy, compare and approve or block agents across tenants. [More info](https://techcommunity.microsoft.com/blog/agent-365-blog/whats-new-in-microsoft-agent-365-ignite-2026/4571753)
- **Action center for agents** (Microsoft 365 admin center, Roadmap): A list of governance tasks, such as inactive and ownerless agents, for review and cleanup. Preview planned for December 2026. [More info](https://techcommunity.microsoft.com/blog/agent-365-blog/whats-new-in-microsoft-agent-365-ignite-2026/4571753)
